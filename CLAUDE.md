## Project Overview

Tab Maestro is a Chrome extension (manifest v3) for saving and managing browser tabs. It uses React 18 with TypeScript, MobX for state management, and SCSS Modules for styling.

## Commands

```bash
# Install dependencies
pnpm install

# Development
pnpm dev              # Start Vite dev server
pnpm build            # Build extension (tsc + vite build)

# Testing
pnpm test             # Run tests once
pnpm test:watch       # Run tests in watch mode

# Linting & Formatting
pnpm lint             # ESLint
pnpm lint:fix         # ESLint auto-fix
pnpm lint:style       # Stylelint
pnpm lint:style:fix   # Stylelint auto-fix
pnpm format           # Prettier format
```

## Chrome Extension Architecture

This extension has three entry points:

| Entry Point | File | Description |
|------------|------|-------------|
| Options Page | `index.html` → `src/main.tsx` → `src/App.tsx` | Main management UI |
| Popup | `popup.html` → `src/popup/main.tsx` → `src/popup/Popup.tsx` | Quick actions popup |
| Background | `src/background/index.ts` | Service worker for shortcuts |

The manifest is generated by `@samrum/vite-plugin-web-extension` from `vite.config.ts`. Permissions include: `tabs`, `storage`, `contextMenus`, `notifications`.

## State Management

MobX is used for state management. The main store is `src/stores/TabStore.ts`, which handles:
- Loading/saving tabs from chrome.storage
- Filtering and searching tabs
- Date range filtering
- Auto-save settings

Components use `observer` from `mobx-react-lite` for reactivity.

## Key Patterns

- **Storage**: All tab data is stored in `chrome.storage.sync` via utilities in `src/utils/storage.ts`
- **SCSS Modules**: Components use `.module.scss` files for scoped styles
- **i18n**: Translation strings are in `src/utils/i18n.ts`
- **Theme**: Light/dark theme support via `src/contexts/ThemeContext.tsx`
