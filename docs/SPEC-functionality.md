# 功能规范

## 核心功能

### 1. 保存当前标签页

- 点击按钮保存当前活动的标签页
- 存储: title, url, favicon, savedAt, originalTabId
- 允许 chrome:// URLs
- 显示成功 toast 通知
- 保存后自动关闭当前标签页

### 2. 保存所有标签页

- 保存所有窗口中的标签页 (排除置顶标签页和扩展页面)
- 显示已保存标签页数量 toast 通知
- 不去重: 所有标签页都会被保存（允许重复保存）
- 保存完成后关闭所有已保存的标签页
- 保存完成后自动切换到选项页面并刷新显示
- 根据规则过滤: 检查域名是否匹配规则，匹配的标签页会被跳过

### 3. 查看已保存标签页

- 列表显示所有已保存标签页
- 按保存时间排序 (最新优先)
- 显示 favicon、URL、保存时间
- 按日期分组显示 (今天、昨天、具体日期)
- 置顶标签页始终显示在最前面

### 4. 打开已保存标签页

- 点击 URL 在新标签页打开
- 点击"打开并删除"按钮打开后从列表中删除

### 5. 删除已保存标签页

- 删除单个标签页
- 全部删除选项

### 6. 清除全部

- 清除所有已保存标签页
- 显示成功 toast 通知

### 7. 置顶功能

- 单个标签页置顶/取消置顶
- 分组批量置顶
- 置顶的标签页始终显示在最前面
- 可以一键打开所有置顶标签页
- 可以一键删除所有置顶标签页

### 8. 分组操作

- 按日期分组显示 (今天、昨天、具体日期)
- 分组批量打开 (打开该分组所有非置顶标签页)
- 分组批量删除 (删除该分组所有标签页)
- 分组批量置顶

## 筛选功能

### 9. 日期范围筛选

- 快捷筛选按钮: 全部/今天/本周/本月
- 自定义日期范围选择器 (开始日期 → 结束日期)
- 清除筛选按钮
- 筛选设置保存到 chrome.storage.sync

### 10. 搜索功能

- 在头部添加搜索框
- 支持按标题和 URL 搜索
- 实时过滤显示匹配的标签页
- 搜索区分大小写，自动转小写比较
- 支持中英文搜索

## 规则管理 (Popup)

### 11. Popup 页面

- 点击扩展图标打开 popup 页面
- 固定宽度 360px，最小高度 400px

### 12. 规则编辑器

- 网站域名输入框
- 快捷日期选择按钮 (每天/工作日/周末)
- 星期按钮网格 (一二三四五六日)
- 时间范围选择器 (开始时间 - 结束时间)
- 保存/取消按钮

### 13. 规则列表

- 规则卡片显示域名和生效日期
- 启用/禁用开关
- 编辑/删除按钮
- 每天显示特殊徽章

### 14. 域名通配符转换

- 自动转换为通配符格式:
  - `www.baidu.com` → `*.baidu.com`
  - `docs.github.com` → `*.github.com`
  - `github.com` → `github.com` (两级域名保持不变)

## 自动保存功能

### 15. 自动保存规则

- 根据规则自动保存符合条件的标签页
- 规则匹配: 域名模式 + 时间段
- 支持通配符域名 (`*.example.com`)
- 支持按星期和时间段控制
- 规则存储在 chrome.storage.local

### 16. 自动保存延迟

- 用户可配置自动保存延迟时间
- 预设选项: 15min, 30min, 45min, 1hour, 1.5hours, 2hours
- 支持自定义任意分钟数
- 设置保存到 chrome.storage.sync

### 17. 后台自动保存

- 用户切换离开标签页时开始计时
- 超过设定延迟时间后自动保存并关闭标签页
- 不保存扩展选项页面
- 发送系统通知提醒用户

## 用户设置

### 18. 主题切换

- 支持浅色/深色/跟随系统 三种模式
- 主题设置保存在 localStorage

### 19. 语言切换

- 支持中文/英文切换
- 语言设置保存在 localStorage
- 切换语言后页面刷新以应用新语言

## 数据处理

### 存储

- **chrome.storage.local**: 标签页数据、规则
- **chrome.storage.sync**: 用户设置 (日期筛选、自动保存延迟)
- **localStorage**: 开发环境降级方案

### 边界情况处理

- 无效 URL 处理
- 离线 favicon 回退 (使用空字符串)
- 过长标题/URL (截断并显示省略号)
- 空标签页列表显示空状态组件

## 快捷操作

### 20. 键盘快捷键

- `Ctrl+Q`: 保存当前标签页
- `Ctrl+Shift+Q`: 保存所有标签页

### 21. 上下文菜单

- 右键点击扩展图标显示菜单
- "Save Current Tab": 保存当前标签页
- "Save All Tabs": 保存所有标签页
