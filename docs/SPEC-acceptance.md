# 验收标准

## 视觉检查点

- [ ] 深色主题与强调色一致应用
- [ ] 卡片有适当的阴影和悬停效果
- [ ] 排版层级清晰
- [ ] 响应式布局适配所有尺寸
- [ ] 空状态视觉效果良好
- [ ] Toast 通知出现并自动消失

## 功能检查点

- [ ] "Save Current Tab" 保存活动标签页
- [ ] "Save All Tabs" 保存所有打开的标签页
- [ ] 已保存标签页正确显示信息
- [ ] 点击标签页在新标签页打开
- [ ] 删除从列表中移除
- [ ] 清除全部需确认后删除所有标签页
- [ ] 浏览器重启后数据持久化

## 技术检查点

- [ ] React + TypeScript 编译无错误
- [ ] MobX store 正确管理状态
- [ ] SCSS modules 正常工作
- [ ] ESLint 无错误通过
- [ ] Vitest 测试运行并通过
- [ ] 扩展在 Chrome 中加载无错误
